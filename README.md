# Olá

Meu único intuito é que esse amontoado de código e exercícios ajude alguém que esteja sofrendo em CÁLCULO 1, 2, 3, ... e minha cabeça que ficará feliz em contar pra ela mesma que eu estou ajudando alguém, mesmo que não saiba quem.

## Alguns pontos
1. Pretendo que as soluções sejam completas, ou seja, você não precisará ficar batendo cabeça com uma passagem obscura.
2. Mais importante que os símbolos matemáticos são os texto que acompanham as resoluções. Eles provavelmente como eu abordei o problema e provavelmente servirá como base para resolver outros exercícios.
3. Não será linear, então não espere que eu inicie no volume 1 pelo capítulo 1, pelo exercício 1, mas na maioria das vezes será isso.
4. Chegarei até tópicos mais avançados =).
5. Fique à vontade para dar sugestões, apontar erros, mas seja educado, tenho baixa tolerância com gente babaca.
